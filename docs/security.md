## 들어오기(인증)

로그인·계정·서버가 없다. 웹 주소를 여는 사람은 누구나 처음부터 끝까지 할 수 있고, 같은 브라우저를 쓰는 다음 사람은 앞사람의 기록을 '이어 하기'로 볼 수 있다. 공용 기기에서는 수업이 끝날 때 타이틀의 '처음부터'(한 번 확인 뒤 진행과 이름을 지움)로 지우는 것이 유일한 정리 방법이다.

## 바깥 요청 금지

- 게임 코드(`js/**`·`css/**`·`index.html`)는 다른 출처로 어떤 요청도 하지 않는다: 글꼴 CDN, 분석 도구, 광고, 원문 사이트 링크 열기 모두 없다. `fetch`·`XMLHttpRequest`·`sendBeacon`·`WebSocket`·`EventSource`·`importScripts`는 같은 출처라도 쓰지 않는다.
- 허용되는 것: 같은 출처의 정적 파일, `data:`·`blob:` 주소, SVG 이름공간 문자열(`http://www.w3.org/2000/svg`, 요청이 아님).
- 원전 안내의 위키문헌 주소는 글로만 적고 게임이 열지 않는다.
- 두 겹으로 확인한다: 저장소 훑기(코드 안의 주소·요청 함수)와 크롬 점검(실제로 나간 요청을 모두 끊고 기록 — 하나라도 있으면 실패).

## 같은 출처의 형제 게임

시리즈 게임이 같은 GitHub Pages 주소(같은 출처)에 올라가면 localStorage를 함께 쓴다. 이 게임은 열쇠를 모두 `isaeng-gyujang:`로 시작하게 해 형제 게임과 섞이지 않게 한다. 이 머리말이 없는 열쇠를 만들거나, 다른 게임의 열쇠를 읽거나 지우지 않는다(`localStorage.clear()`는 점검 도구의 새 크롬 맥락에서만 쓴다).

## 남는 기록

서버 기록은 없다. 학습 증거로 남는 것은 학생 기기의 기록뿐이고, 다음 사건이 일어나면 그 자리에서 저장된다: 수단을 씀(시도 번호와 수단), 빈칸에 카드를 넣음(처음 카드, 최종 낱말), 이생에게 답함(답한 차례), 낱말 카드를 얻음, 3막 할 일을 마침, 경계를 겪음, 혼이 열림, 마음 둔 곳을 고름, 쓰기 셋을 마침(글), 근거 장면을 고름, 만복사 두 고르기(사실 공개 전), 바로가기로 막을 건너뜀, 이름을 적음. '처음부터'를 하면 이 기록과 이름이 모두 지워진다.

## 비밀 값

게임에는 비밀 값(키·토큰)이 없다. 만드는 쪽에서 다루는 비밀은 하나다: 그림 시안 도구(`tools/gen.ps1`)가 Codex 로그인 파일(`~/.codex/auth.json`)을 임시 폴더(`%TEMP%\codex-img-isaeng-<이름>`)에 복사해 쓰고 끝나면 지운다. 이 파일이나 그 복사본을 저장소에 넣지 않는다. 생성 원본(`assets/raw/`)은 git에서 빠져 있다.

## 저장소 공개 범위

- 저장소 `pblsketch/isaeng-gyujang-jeon`은 **공개**이고 GitHub Pages로 게임을 내보낸다(2026-10-10 전환). 저장소에 들어간 모든 파일과 이력은 누구나 볼 수 있다.
- 기획 폴더 `design/`(교과서 쪽수가 적힌 글 목록, 외부 검토와 채점 기준표, 그림 시안)은 공개 전에 git 기록에서까지 지웠고 지금은 `.gitignore`로 막혀 만드는 컴퓨터에만 있다. 다시 추적하지 않는다 — 한 번 커밋해 올리면 이력에 남아 다시 이력을 고쳐 써야 한다.
- 원문 사본 `sources/wikisource-geumosinhwa-raw.txt`는 위키문헌 「번역:금오신화」의 한문 원문(공유 저작물)이라 공개 저장소에 둔다. 교과서·지도서·번역서의 글은 이 폴더에도 넣지 않는다.
- 교과서 출판사 이름은 공개 여부와 상관없이 파일 이름·내용·커밋 글·커밋 이력의 변경 내용·브랜치·태그 이름 어디에도 없어야 한다. 점검 코드도 그 이름을 글자 번호(`String.fromCodePoint`)로만 만든다.
- 교과서·지도서 PDF와 그 추출본은 저장소 폴더 밖(상위 폴더와 임시 폴더)에만 둔다.
- 모든 그림·소리·글꼴은 상업 납품이 가능한 조건(자체 생성물, 공공누리 제1유형, SIL OFL)이고 `credits/*.tsv`에 한 줄씩, '상업적 이용'이 `가능`으로 있어야 한다.
