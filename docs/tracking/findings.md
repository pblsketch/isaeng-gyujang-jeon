# 아직 풀지 못한 문제

## 수업 시간 가설과 화면 글 분량

- **무엇이 문제인가**: 놀이 목표는 약 28분(수업 여유 약 7분)인데, 학생이 읽어야 하는 화면 글이 한글 약 7,300자와 한문 원문 576자다(고른 것에 따라 더해지는 반응 글과 옥루춘 회상 글은 뺀 값). 1분에 300~400자를 읽는다고 하면 읽기만 약 18~24분이고, 여기에 걷기·고르기·한 줄 쓰기 세 번·반응 글이 더해진다. 자동 진행으로 잰 시간은 어느 입력 방식이든 61~70초라 실제 시간을 알려 주지 못한다.
- **왜 중요한가**: 한 차시 안에 결과 화면까지 가지 못하면 학습 증거(결과 그림)가 남지 않고, 「만복사저포기」 전이와 쓰기 셋이 빠진다. 수업 설계 전체가 걸린 문제다.
- **왜 지금 풀 수 없나**: 실제 학생의 읽기·조작 시간은 교실 시범 플레이(글을 천천히 읽는 학생, 조작이 처음인 학생 포함)로만 잴 수 있다. 무엇을 줄일지는 사용자가 정한다.
- **해 볼 수 있는 것**: 시범 플레이에서 장면별 시작·끝 시각과 막히는 곳(지금 할 일을 못 찾음, 경계를 못 찾음, 한 줄 쓰기에서 멈춤)을 적는다. 넘치면 걷는 길과 장면 글부터 줄이고, 그래도 넘치면 1막을 더 줄이거나 「만복사저포기」를 선택 활동으로 돌리는 것을 사용자와 정한다.

## 교사가 글을 '확인됨'으로 바꾸면 전체 점검이 실패한다

- **무엇이 문제인가**: 글 자료 점검(`tests/check-data.mjs`)은 모든 글 덩이와 원문 덩이의 상태가 `확인 전`이기를 요구한다(`STATUS = '확인 전'`과 같지 않으면 실패). 교사가 글 확인을 마치고 자료 파일의 `status`를 `확인됨`으로 바꾸는 순간, 다른 것은 아무것도 바꾸지 않아도 `node tests/run-all.mjs`가 종료 1로 끝난다.
- **왜 중요한가**: 교사 확인은 남은 일의 첫 번째이고, 완료 관문은 전체 점검 종료 0이다. 그대로 두면 확인 작업이 곧 점검 실패가 되어, 상태를 되돌리거나 점검을 급히 고치게 된다.
- **왜 지금 풀 수 없나**: '이번 판의 모든 글은 확인 전'이 이번 판의 점검 기준으로 정해져 있다. 확인 뒤의 기준(두 상태 모두 허용할지, 원문은 확인됨을 요구할지, 확인한 사람·날을 남길지)은 교사 확인 방식이 정해져야 고를 수 있고, 점검 기준을 바꾸는 것은 사용자 결정이다.
- **해 볼 수 있는 것**: 상태 검사를 `['확인 전', '확인됨']` 가운데 하나로 바꾸고, 글 확인 문서의 개수 표에 상태별 개수를 더한다. 교사 확인을 시작하기 전에 사용자와 정한다.

## 공개 전 기획 폴더를 지우면 원문 대조가 끊긴다

- **무엇이 문제인가**: 공개 전에는 기획 폴더 `design/`을 git 기록에서까지 지우기로 했다. 그런데 원문 사본 `design/sources/wikisource-geumosinhwa-raw.txt`를 글 자료 점검(`tests/lib-data.mjs` → `check-data.mjs`의 원문 한자 대조)이 읽고, 글 확인 도구(`tools/review-doc.mjs`)가 출처 경로로 적으며, 원문은 이 사본에서만 옮긴다는 규칙도 이 경로를 가리킨다. `design/`을 그대로 지우면 `node tests/run-all.mjs`가 종료 1로 끝나고 원문 규칙이 없는 파일을 가리킨다. 그림 시안 도구(`tools/drafts.py`)의 출력 경로도 `design/art-drafts/`다.
- **왜 중요한가**: 원문 한자를 지어 넣지 않았다는 증거가 원문 대조 점검이다. 사본이 사라지면 그 점검을 끄거나 고쳐야 하고, 공개 직전에 완료 관문이 깨진다.
- **왜 지금 풀 수 없나**: 사본을 어디로 옮길지(공개 저장소에 원문 사본을 둘지, 어떤 폴더 이름으로 둘지)는 공개 범위에 관한 사용자 결정이다. 공개 전환 자체가 아직 정해지지 않았다.
- **해 볼 수 있는 것**: 공개를 정할 때 사본을 `sources/` 같은 추적 폴더로 옮기고 `tests/lib-data.mjs`·`tools/review-doc.mjs`의 경로와 원문 규칙을 함께 고친 뒤 전체 점검을 돌린다. 그다음에 `design/`의 이력을 지운다.
