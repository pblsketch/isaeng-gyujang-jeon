## 만들었지만 점검으로 확인하지 못한 것

- **실제 기기**: 휴대폰·태블릿·크롬북에서 직접 해 보지 않았다. 크롬 점검은 PC 크롬에서 휴대폰 가로 크기(844×390, 640×360)와 터치를 흉내 낸 것이다.
- **수업 시간**: 놀이 약 28분은 가설이다. 자동 진행은 어느 입력 방식이든 1분 남짓이라 읽고 쓰는 시간을 재지 못했다(화면 글 약 7,300자 + 원문 576자).
- **글 내용의 정확성**: 모든 글이 `확인 전`이다. 교사가 글 확인 문서로 보기 전에는 풀이의 뜻, 교과서와의 대조, 2막 수위가 확인되지 않은 상태다.
- **그림 시안**: 네 화풍(그림책풍·수묵 담채·민화·웹툰풍)을 같은 장면과 지도 조각으로 그려 `design/art-drafts/`에 두었고, 사용자가 2026-10-09에 **그림책풍**을 골랐다. 게임에는 아직 그림이 들어가지 않았다(코드로 그린 타일, 단색 사람 모양, 빈 종이 판).
- **올리기**: 원격 저장소에는 첫 커밋(소개 글)만 있고 그 뒤 작업은 아직 올리지 않았다. GitHub Pages는 켜지 않았다.

## 남은 일(차례대로)

1. **교사 글 확인**: 글 확인 문서(`node tools/review-doc.mjs`가 만드는 글 모음)로 모든 글을 본다. 특히 2막 도적 장면의 수위(위협 한 줄, 꾸짖음 뒤 암전, 접힌 원문 카드), 3막 '시 주고받기'의 원문 한 구, 혼이 열리는 까닭의 원문을 2막으로 앞당겨 보인 것. 확인한 글을 `확인됨`으로 바꾸고, 그때 글 자료 점검의 '모두 확인 전' 검사를 함께 바꾼다.
2. **실제 기기와 수업 시간**: 휴대폰 가로·크롬북·태블릿에서 해 보고, 교실 시범 플레이로 장면별 시간을 잰다(글을 천천히 읽는 학생, 조작이 처음인 학생을 따로). 넘치면 걷는 길과 장면 글부터 줄이고, 그래도 넘치면 1막을 더 줄이거나 「만복사저포기」를 선택 활동으로 돌리는 것을 사용자와 정한다.
3. **본 그림(그림책풍)**: 장면 삽화, 인물 초상, 지도 타일, 인물 도트. 시안에서 조선식으로 나온 옷차림(한복, 갓)을 고려 말 옷차림으로 맞춘다. 폭력·죽음 장면은 그리지 않는다. 그림은 `window.ART`에 등록하고 `credits/`에 상업 이용 가능 조건으로 한 줄씩 더한다. 그림 생성은 할 때마다 사용자 승인.
4. **올리기**: 사용자 승인 뒤 `main`을 원격에 올린다.
5. **공개 전환과 GitHub Pages**: 사용자 승인 뒤, 먼저 원문 사본(`design/sources/`)을 추적 폴더로 옮기고 그 경로를 쓰는 자료 점검·글 확인 도구를 고쳐 전체 점검 종료 0을 본 다음, `design/`을 git 기록에서 지우고 공개로 바꾼 다음 Pages를 켠다.
6. (시리즈) 「빼면 무엇이 사라질까」 이야기꾼 활동은 이 게임 밖의 수업 정리 활동으로 따로 쓸 수 있다.
