# 0011 웹 주소로만 열고 파일 더블클릭 열기는 지원하지 않는다

- 날짜: 2026-10-09 · 상태: 정함(사용자 선택)

## 맥락

「최척전」 엔진에는 파일을 더블클릭해(`file://`로) 열어도 돌아가게 하는 장치(배경음을 base64로 내장한 파일과 그것을 쓰는 코드)가 있었다. 엔진을 가져오면서 이것을 함께 가져올지 정해야 했다.

## 결정

GitHub Pages나 내 컴퓨터의 간이 서버(`python -m http.server`) 같은 웹 주소로만 연다. 파일 더블클릭 열기와 base64 배경음은 가져오지 않았다.

## 다른 안

- **파일 열기 지원 유지**: 서버 없이 파일만 나눠 줘도 열 수 있지만, 배경음을 내장한 큰 파일과 그 처리 코드를 이 게임에도 두어야 한다. 사용자가 고르지 않았다.

## 결과

- 수업에서 쓰려면 Pages 주소가 있거나 교사 컴퓨터에서 간이 서버를 띄워야 한다. Pages는 공개 전환 뒤에만 켤 수 있다.
- 점검 도구도 늘 내장 정적 서버(빈 포트)로 연다.
- 게임 코드에는 `file://` 감지·우회 코드가 없고, 두지 않는다.
