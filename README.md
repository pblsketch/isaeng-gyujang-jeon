# 이생규장전: 세 번의 담 (가제)

**만든이**: 박준일 (온양여자고등학교 국어 교사)

김시습의 전기 소설 「이생규장전」을 위한 고등학생용 고전문학 학습 게임입니다. 지금은 **설계 단계**입니다.

> 학생은 최 씨가 되어 부모의 반대, 전란, 생사의 경계라는 세 번의 담에 맞서며, 만남과 이별이 되풀이되는 구조와 전기적 요소의 효과, 최 씨의 인물됨과 시대 상황을 익힌다.

- 별도 설치나 계정 없이 브라우저에서 실행합니다. 가로 화면을 기본으로 합니다.
- 진행 기록은 그 브라우저에만 저장합니다(서버로 보내지 않음).

설계가 정해지면 실행 방법과 구성을 이곳에 적습니다.
