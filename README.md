# 이생규장전: 세 번의 담 (가제)

**만든이**: 박준일 (온양여자고등학교 국어 교사)

김시습의 전기 소설 「이생규장전」(『금오신화』)을 위한 고등학생용 고전문학 학습 게임입니다. 고등학교 『문학』 수업 한 차시(35~45분)에 학생 한 명이 혼자 합니다.

> 학생은 최 씨가 되어 부모의 반대, 전란, 생사의 경계라는 세 번의 담에 맞서며, 만남과 이별이 되풀이되는 구조와 전기적 요소의 효과, 최 씨의 인물됨과 시대 상황을 익힌다.

- 별도 설치나 계정 없이 브라우저에서 실행합니다. **가로 화면 전용**입니다(휴대폰 가로, 크롬북, 태블릿, PC). 세로로 들면 돌려 달라는 안내가 나옵니다.
- 진행 기록은 그 브라우저에만 저장합니다(서버로 보내지 않음). 바깥 주소로 요청하지 않습니다(글꼴·음원 모두 저장소 안에 있음).
- 점수, 등급, 순위, 시간 제한, 게임 오버가 없습니다. 틀려도 끝까지 갈 수 있습니다.

## 실행 방법

웹 주소로만 엽니다(파일을 더블클릭해 여는 것은 지원하지 않습니다).

- **GitHub Pages**에 올렸다면 그 주소를 엽니다.
- **내 컴퓨터에서**: 이 폴더에서 간이 서버를 띄우고 브라우저로 엽니다.
  ```
  python -m http.server 8000
  ```
  → `http://localhost:8000/`

### 막 바로가기(선생님 시연, 빠진 학생 따라잡기)

| 주소 | 시작 |
| --- | --- |
| `…/?act=1` | 1막 「부모의 담」부터 |
| `…/?act=2` | 2막 「전란의 담」부터(1막은 30초 요약 카드) |
| `…/?act=3` | 3막 「저승의 담」부터(1·2막은 요약 카드, 혼은 열린 채) |

저장 기록이 있으면 '이어 하기 / 이 막부터'를 고릅니다. 건너뛴 막의 빈칸은 원작 낱말로 채워지고 결과 화면에 '하지 않음'으로 남습니다.

## 구성

핵심 고리: **담이 막는다 → 최 씨가 수단(말·시·결단·혼)을 골라 맞선다 → 세계가 원작의 논리로 답한다.** 원작과 다른 수단을 써도 벌은 없고 담 높이만 눈에 보이게 달라집니다. 큰 줄거리와 결말은 바뀌지 않습니다.

| 순서 | 장면 | 하는 일 | 기본 시간 |
| --- | --- | --- | --- |
| 1 | 들어가기 | 송도, 두 사람을 칭찬하는 노래(원문·풀이), 미션, 표시 다섯 안내 | 1분 |
| 2 | 1막 「부모의 담」 | 최 씨 집 정원 한 판. 조작 익히기(걷기 → 향아에게 말 걸기 → 수단 고르기), 담 앞 순간 둘(이생의 시에 답하기 · 부모 앞에서 털어놓기), 막 끝 빈칸 | 4분 |
| 3 | 2막 「전란의 담」 | 피란길(한 방향 길), 도적 앞 순간(꾸짖음 → 암전), 이생 쪽 카드, 밤의 낭하에서 혼(환체)이 열림(전기적 요소), 재회, 막 끝 빈칸 | 7분 |
| 4 | 3막 「저승의 담」 | 세 구역(최 씨 집 · 골짜기와 들 · 오관산 기슭). 할 일 넷(재물 · 유골 · 시 주고받기 · 장사), 보이지 않는 경계, 마음 둔 곳, 옥루춘(회상이 마음 둔 곳에 따라 바뀜), 이생의 제안에 답하기, 이별 | 9분 |
| 5 | 반복의 뜻 한 문장 · 전기적 요소 한 줄 | 만남과 이별 표를 보고 한 문장, 근거 장면을 고르고 한 줄 | 2분 |
| 6 | 「만복사저포기」 함께 보기 | 새로 쓴 줄거리 → 두 고르기(사실 공개 전 기록) → 한 줄 | 3분 |
| 7 | 결과 화면 | 되짚기와 캡처(그림 파일로 저장) | 2분 |

놀이는 약 28분을 목표로 하고 수업 설명·기기 문제·정리를 위한 여유 약 7분을 남깁니다. 이 시간은 실제 수업에서 확인할 가설입니다. 자동 진행으로 잰 시간과 읽기 분량은 [`docs/시범-플레이-시간.md`](docs/시범-플레이-시간.md)에 있습니다.

### 결과 화면에 남는 것

이름(선택) · 만남과 이별 표(칸마다 최종 낱말과, 다를 때 처음 고른 낱말) · 반복의 뜻 문장 · 담 앞 순간마다 써 본 수단의 차례 · 3막에서 마음 둔 곳과 이생에게 처음 한 답 · 쓴 글 셋과 근거 장면 · 만복사 두 고르기 · 되짚기 질문 둘 · 「김현감호」 한 줄 · 원전으로 나가는 문(게임에 나온 원문·풀이 대목 모음과 전문을 읽을 곳 안내). 학생은 이 화면을 캡처하거나 그림 파일로 저장해 냅니다.

## 표시 다섯 가지

게임의 모든 글과 카드에 하나가 붙습니다.

| 표시 | 뜻 |
| --- | --- |
| 원문 | 작품에 실제로 적힌 한문 그대로(늘 풀이와 짝) |
| 풀이 | 원문을 이 게임이 새로 옮긴 것 |
| 게임 설정 | 게임이 지어낸 장면·규칙·대사(수단, 담 높이, 낱말 카드, 마음 둔 곳, 혼으로 걷는 길 등) |
| 이본 노트 | 판본마다 다른 곳 |
| 해석 | 정답이 없는 하나의 읽기 |

## 출처

- **원문**: 위키문헌 「번역:금오신화」의 李生窺牆傳·萬福寺樗蒲記(공유 저작물). 풀이와 장면 글은 모두 이 게임이 새로 썼습니다(교과서·지도서·번역서의 번역문을 쓰지 않음).
- **배경음**: 국립국악원 「디지털 이음」 음원, 공공누리 제1유형 — [`credits/bgm.tsv`](credits/bgm.tsv)
- **글꼴**: 고운바탕, Noto Serif KR·SC, 나눔손글씨 붓(모두 SIL Open Font License 1.1) — [`credits/fonts.tsv`](credits/fonts.tsv), [`assets/fonts/OFL.txt`](assets/fonts/OFL.txt)
- **그림**: 이번 판은 코드로 그린 타일과 임시 그림입니다. 화풍은 시안을 보고 그림책풍으로 정했고, 본 그림은 다음 판에서 만듭니다.

## 교사 확인 목록

- 게임에 실린 글(원문·풀이, 수단 반응, 낱말 카드, 옥루춘 회상, 만복사 줄거리와 보기, 되짚기 질문, 3막 시 한 구 등)은 [`docs/글-확인.md`](docs/글-확인.md)에 출처·표시·상태와 함께 모여 있습니다. 이번 판의 모든 글은 `확인 전`입니다.
- 확인을 마친 글은 자료 파일(`js/data/`)에서 상태를 `확인됨`으로 바꾸고 `node tools/review-doc.mjs`로 문서를 다시 만듭니다(문서를 손으로 고치지 않습니다). 상태를 바꿀 때는 `tests/check-data.mjs`의 '모두 확인 전' 검사도 함께 고칩니다.
- 특히 볼 곳: 2막 도적 장면의 수위(위협 한 줄, 꾸짖음 뒤 암전, 원문 카드는 접혀 있음), 3막 '시 주고받기'의 원문 한 구, 혼이 열리는 까닭의 원문을 2막에 앞당겨 보인 것(`게임 설정` 안내 있음).

## 점검(만드는 사람용)

Node 18 이상, 설치된 Chrome, Python 3(fontTools — 글꼴 점검)이 필요합니다. Playwright는 `tests/node_modules`에 둡니다.

```
node tests/run-all.mjs          # 모든 점검(0으로 끝나야 완료)
node tests/run-all.mjs act1     # 이름에 그 낱말이 든 점검만
node tools/review-doc.mjs       # 글 확인 문서 다시 만들기
python tools/build_fonts.py     # 글이 바뀌어 새 글자가 생겼을 때 부분 글꼴 다시 만들기
```
